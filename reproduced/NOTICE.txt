This folder contains result artifacts (JSON, xlsx, log files) produced by
running the MalLoc and RAML baseline systems on this project's own test
applications. It does not contain MalLoc's or RAML's source code.

The MIT LICENSE at the root of this repository covers AGLL's own code and
these generated result files. It does not extend to, and makes no claim
over, MalLoc or RAML themselves, which are separate third-party research
artifacts:

  MalLoc: https://github.com/Trustworthy-Software/MalLoc
  RAML:   https://github.com/Trustworthy-Software/RAML

Neither upstream repository ships an explicit license file as of this
writing. Obtain MalLoc's and RAML's own code directly from their
repositories above under whatever terms their authors provide, rather than
from this repository.

Directory and file names under malloc/ were changed after the runs so that
they follow one pattern (malapp_1_9_11, synthetic_malapp, realistic_malapp) and
so that no file name contains a colon, which Windows does not allow. File
contents were not modified. For the synthetic app, ":" in the model tag of
llm_interaction_*.json became "_".
